# enigma
This is an electronic model of Enigma. You can change the rotors and encode and decode text.
## Installation

First, you need to clone this repository:

```bash
git clone git@github.com:lucyhmiller1/enigma.git
```

Or:

```bash
git clone https://github.com/lucyhmiller1/enigma.git
```

Then change into the `enigma` folder:

```bash
cd enigma
```

Now, we will need to install the 'flask' dependency:

```bash
pip install flask
```

## How to run the Enigma application

```bash
python3 app.py
```

The applications will run on http://localhost:5000
